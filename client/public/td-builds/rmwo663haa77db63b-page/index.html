Safe Chat

Private messaging that stays private

What is Safe Chat?

Safe Chat is a private chat app — every message is scrambled on your phone before it is sent.

The key lives in the invite link, and the server only stores scrambled text that it cannot read.

How to Start a Room

To start a room:

  1. Open Safe Chat.
  2. Create a room.
  3. Share the invite link.
Warning: anyone who has the room link can read the room, so share it carefully.
