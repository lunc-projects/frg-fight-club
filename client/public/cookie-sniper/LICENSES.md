# COOKIE SNIPER — third-party asset licenses

COOKIE SNIPER is an original game made for the DO community. Every
character in it — the cookie monsters — is an original design built at
runtime from procedural geometry (cookie-disc bodies, googly eyes,
stubby limbs) with procedural canvas textures. No third-party character,
name, likeness, model, animation, or artwork is used anywhere in this
folder, and no assets were copied from any commercial game.

## Engine — three.js (MIT)

`lib/three.module.js` and `lib/addons/` are three.js r160, MIT License,
Copyright © 2010–2023 three.js authors. (The addons folder ships with the
library; this game itself uses only the core module.)

## Game code & art

All game code, HUD, text, procedural textures, sound synthesis, and the
cookie-monster designs are original work for this project (2026).
