ℹ️ About & helper access

This app runs on two keys. The 🔑 Master Creator Key is the owner's — it opens everything, and it never leaves the owner.

A 🧑‍🔧 Helper Key opens the day-to-day controls only: problems and their fixes, website help, orders, the tools, and status. It can never touch the emergency switches, the signing pages (above all the private ones), the Everything Book, the money records, or the ↩️ Reverse key (taking a project back and refunding it) — the server refuses, not just this page. Work done with a Helper Key is recorded as the helper's, so the owner can see exactly what was done.

Owner — giving or taking away access: a helper's key is the HELPER_SECRET value on the studio server (Railway → the intake service → Variables). Set it to hand a helper their key. To take access away, change that value — the old key stops working the moment the service restarts with the new one. Your Master Creator Key is a separate value and is never shared.

📲 Install this app: in Chrome, tap the ⋮ menu → “Add to Home screen.” It gets its own icon and opens full-screen, like a real app.
