🛡️ Garuda — Take Back Admin

If you hold the current admin key for any contract below, this page lets you take it back: transfer its admin to a fresh wallet, or renounce it to the burn address so it can never be migrated again. Only the current admin's signature works — this page cannot seize control from anyone. Revoking the migration grant (first card) closes the door used in the October 31 drains.

⚠️ Read before you sign

  • Renouncing is permanent. It sends the admin to the burn address — after that NO ONE can ever migrate or re-admin that contract again. There is no way back.
  • Transfer is only as safe as the address you type. Check the new address character by character in your wallet app before approving. A typo hands the contract to a stranger's wallet, forever.
  • Every action here can only be signed by the contract's current admin (or, for the grant, the granter). The chain rejects everyone else — the buttons below only light up for the right wallet.
  • Your seed phrase must never be shared — not in a chat, not typed into any website. This page never asks for it. Anyone who does is a scammer.
  • This page holds no keys and signs nothing on any server. Signing happens only inside your own wallet app.
