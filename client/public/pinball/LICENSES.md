# Luna Pinball — asset licenses

Everything in this game is original work created for LUNC Dev Studio:

- **Code** — original JavaScript (custom 2D physics engine, no third-party game
  engine or pinball library). Written for this project.
- **Art** — 100% procedural: the playfield, moon centerpiece, bumpers, ramps,
  cabinet, coin door and dot-matrix display are all drawn at runtime with the
  Canvas 2D API. No images, sprites, fonts or sound files are loaded.
- **Sound** — every effect is synthesized live with the Web Audio API
  (oscillators + filtered noise). No audio files.
- **Theme** — "Luna Classic Orbit Station" is an original space theme built
  around the Luna Classic crescent and USTC star marks used across the LUNC
  Dev Studio arcade. No franchise art, names, layouts or assets from any
  commercial pinball machine are used; the design only follows the universal
  vocabulary of pinball (flippers, bumpers, ramps, lanes) the way any real
  machine does.
- **Fonts** — system font stack only.

No third-party assets are included, so no attribution is required.
