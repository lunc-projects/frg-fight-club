# Candle Chaos — licenses & asset provenance

Candle Chaos is an original LUNC Dev Studio game. Everything in this
folder was created for this game; there are no third-party art,
model, sound, or font assets.

- **Game code, characters, and world** — original, procedural
  (Three.js scene built entirely in code: the runner character, the
  candle blocks, flames, pickups, city and chart backdrop are all
  generated at runtime; textures are drawn on canvas at runtime).
- **Menu key art** (`keyart.webp`) — AI-generated artwork created for
  LUNC Dev Studio for this game (Nov 7, 2026), used as the menu hero
  image and Arcade card art basis.
- **Sound** — tiny WebAudio synth effects generated in code at
  runtime. No audio files.
- **Engine** — Three.js r160 (`lib/three.module.js`), MIT License,
  © Three.js authors. https://threejs.org
- **Fonts** — system font stack only; no bundled fonts.

Gameplay tokens shown are LUNC (Luna Classic) crescents and USTC
stars, the studio's own house pickups. This is a free game: it never
asks players to connect a wallet or sign anything.
