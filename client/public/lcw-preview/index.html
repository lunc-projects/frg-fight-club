About LCW

Luna Classic World (LCW) is a CW20 token on the Terra Classic blockchain. LCW trades against LUNC in a live liquidity pool, so anyone can buy or sell it on the open market, any time.

How to buy LCW

  1. Get a Terra Classic wallet (for example Keplr or LUNCDash) and hold some LUNC in it.
  2. Open Vyntrex, OrbitWire or Terraport using the Buy buttons above.
  3. On the market page, swap LUNC for LCW. Check the contract address matches the one on this page.
  4. Done — your LCW arrives in the same wallet.
