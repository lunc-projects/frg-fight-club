# Luna Balloon Breakout — asset licenses

Everything in this game is original work created for LUNC Dev Studio:

- **Code** — original JavaScript (custom canvas physics + balloon field,
  no third-party game engine or breakout library). Written for this project.
- **Art** — 100% procedural at runtime with the Canvas 2D API: the glossy
  balloons (bodies, highlights, knots, strings), paddle, golden ball, dusk
  carnival sky, skyline, bunting and pop bursts are all drawn in code.
  No sprite or image files are loaded for gameplay.
- **Brand marks** — the two embedded images are the project's own Luna
  Classic artwork (the official community crescent mark and the LUNA CLASSIC
  lockup) carried over from the previous build of this same game, where they
  shipped as the game's badge and special-block art.
- **Sound** — every effect is synthesized live with the Web Audio API
  (oscillators + filtered noise bursts for the pops). No audio files.
- **Theme** — "Balloon Breakout" is an original carnival-sky theme built
  around the Luna Classic crescent and USTC star marks used across the LUNC
  Dev Studio arcade. The design follows only the universal vocabulary of
  breakout games (paddle, ball, clear the field).
- **Fonts** — system font stack only.

No third-party assets are included, so no attribution is required.
